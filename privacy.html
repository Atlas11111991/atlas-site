Privacy Policy

Applies to the Atlas personal assistant application. Last updated: September 2026.

Atlas is a private, single-user application running on a personal server. This policy explains how the application accesses, uses, stores and shares data obtained from Google APIs — and, just as importantly, what it does not do with it.

1. Whose data this covers

Atlas serves exactly one person: the owner and operator of the server it runs on, who is also the sole holder of the Google Account it is authorised against. There are no other users, no accounts to create, and no third parties whose data Atlas touches.

2. What Atlas accesses, and why

Google serviceScope of accessWhy
Gmail Read, modify (labels / read state), and send To search and summarise the operator's mail, flag messages, and send replies or new messages that the operator has explicitly reviewed and approved.
Google Calendar Read and write events To show upcoming events, detect scheduling conflicts, prepare meeting briefings, and create events at the operator's request.
Google Drive Read and write files To store and organise notes, drafts and exports in the operator's own Drive, in a folder called Atlas Hub.
Google Docs & Sheets Read and write documents and spreadsheets To create and update notes, reports and an index spreadsheet belonging to the operator.
Google Contacts Read-only To look up a contact's details while drafting correspondence.

Atlas requests access only to the categories above and uses each one solely for the functions described. It does not request or store other Google data.

3. Where the data lives

Data obtained through the Google APIs is processed and stored on the operator's own private server. OAuth credentials (a refresh token) are held in a protected file readable only by the application's own service account, alongside a client secret that is never transmitted to third parties. The server's backups are encrypted before leaving the machine, and no unencrypted copy is placed on any third-party storage service.

4. No sharing, no sale, no advertising use

  • Google user data is never sold, rented, or transferred to anyone.
  • It is never used for advertising, profiling, creditworthiness, lending, or insurance decisions.
  • It is not used to train, fine-tune, or otherwise improve any general-purpose AI model.
  • No human other than the operator reads it, because there is no other person involved in running Atlas.
  • Sub-processors that may see it in transit are limited to the model provider that generates the text replies, and only for the single request being answered. No data is retained by them for Atlas.

5. Google API Services User Data Policy — Limited Use

Atlas's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. In particular, Google user data is used only to provide the features described in section 2, is not transferred to others except as necessary to provide or improve those features, and is not used for advertising.

6. Retention and deletion

Information is kept only as long as it is useful to the operator, who can delete it at any time. Access can be revoked at any moment, either from the application (which discards the stored token) or from the Google Account's third-party access settings. Once access is revoked, Atlas can no longer reach the account, and any cached copies on the server can be deleted on request. To request deletion of anything held, write to the address below.

7. Security

Credentials are stored with restrictive file permissions on a private server, are excluded from version control, and are stored encrypted in off-site backups. Transport to and from Google APIs is over TLS.

8. Changes to this policy

If the data Atlas accesses changes, this page will be updated to describe the new access before it is used.
